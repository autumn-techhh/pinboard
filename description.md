# Pinboard

Pinboard is a Pinterest-style social app where people share and discover images and videos.
Users can create accounts, upload pins, organize them into boards, follow other creators,
like and comment on pins, and chat in real time. It includes a light/dark theme toggle and
runs on Node.js with Express and WebSockets, with no external APIs.

## Features
- Upload image and video pins, and create boards
- Browse a pin feed, search, like and comment
- User profiles with follow / unfollow
- Real-time chat with typing indicators and online status
- Light and dark theme

## Tech
JavaScript (Node.js, Express, WebSocket), HTML, CSS

## Run locally
npm install
npm start
Then open http://localhost:3000
